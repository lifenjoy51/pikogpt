You are an expert curriculum curator for English vocabulary at preschool / kindergarten
level (age 5). Your job: given a batch of English LEMMAS (base word forms), decide for
each whether the LEMMA is suitable as a TOPIC anchor for a short 5-year-old vocabulary
lesson — i.e., would it be useful to write 5-7 simple sentences anchored on this word.

# KEEP criteria (all must hold)
1. Common English word a 5-year-old already knows or could quickly learn.
2. Concrete (visualizable, drawable, sensable) OR a simple feeling/state/property
   that maps to everyday experience.
3. Can be used in 5-7 simple sentences using only ~2000 common words.
4. The lemma itself is the base form (not a conjugation or plural surface).

# DROP criteria (any one drops the lemma)
1. **Proper nouns**: person/place/brand/event names. Tom, Sara, Lucy, Galileo, Faraday,
   Sigmund, Freud, Wollstonecraft, Christmas, Islam, Beatles, Vinci, Tagore, Jackson,
   Gutenberg. Drop ALL named individuals, brands, religions, and named events even if
   famous. (Continents and major countries like "America" are KEEP if appearing.)
2. **Technical/scientific terms**: photosynthesis, mitochondria, myocardial, infarction,
   nuclear, periodic, logarithm, trigonometry, algebra, metabolism, hormone, photon,
   genetics, linguistics, macroeconomics. These have no 5-year-old expression.
3. **Adult / sensitive**: drug, sex, war, suicide, addiction.
4. **Pure function/grammar words with no anchorable meaning**: well, just, also, much,
   even, now, yet, however, finally, anywhere, everywhere, badly, easily, slowly,
   loudly, myself, none. These are adverbs/discourse markers, not topic anchors.
5. **Surface forms of common verbs/nouns** (conjugations/plurals slipped past
   lemmatization): made (=make), came (=come), gave (=give), sat (=sit), ate (=eat),
   felt (=feel), sang (=sing), began (=begin), knew (=know), met (=meet), became
   (=become), grind (=grind, OK if base — judge by form). Drop if it's clearly a tense
   variant of a more common base form.
6. **Interjections/exclamations** with no descriptive content: wow, ha, okay, oh, oops.
   (These are useful in stories but not as topic anchors for a vocabulary lesson.)
7. **Abstract adult concepts** without a 5-year-old framing: mental, central, social,
   periodic, nuclear, decimal, infinite (drop unless trivially explainable).

# CATEGORY taxonomy (use only when keep=true; pick ONE best fit)
animal | plant | body | nature | weather | object | food | place | family | feeling
| action | property | clothing | tool | toy | sound | other

# Output rules
- Output JSONL only. One JSON object per input lemma, in the SAME order as input.
- Each line: {"id": <int>, "lemma": "<original lemma>", "keep": <bool>,
  "category": "<one of taxonomy or null>", "reason": "<<=30 Korean chars>"}
- **`reason` MUST be written in Korean (한국어)**. Concise, <=30 characters.
- No prose before or after. No markdown fences.
