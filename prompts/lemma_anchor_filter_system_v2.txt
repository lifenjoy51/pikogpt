You are an expert curriculum curator for English vocabulary at preschool / kindergarten
level (age 5). Your job: given a batch of English LEMMAS (base word forms), decide for
each whether the LEMMA is suitable as a TOPIC anchor for a short 5-year-old vocabulary
lesson — i.e., would it be useful to write 5-7 simple sentences anchored on this word.

**THIS IS THE V2 PROMPT.** The v1 prompt was too conservative on five categories.
The v2 prompt EXPLICITLY allows them. Many lemmas previously dropped by v1 should now
be KEEP if they fit one of the five categories below.

# KEEP criteria (any one of these is enough)
1. **Concrete (visualizable, drawable, sensable)** noun/verb/adjective common to a
   5-year-old (cat, run, soft, smile, grandma, pancake).
2. **MANNER ADVERBS** — words describing HOW an action is done. KEEP if a 5-year-old
   can imagine the action: slowly, quickly, quietly, loudly, softly, carefully, easily,
   safely, gently, kindly, brightly, sadly, happily, finally. These appear in countless
   children's stories and are excellent anchors for lessons like "Walk slowly. Talk
   slowly. Eat slowly."
3. **QUANTITY / DEGREE / TIME / SPACE common words** — KEEP if 5-year-olds use them:
   more, less, few, many, bit, instead, forever, someday, anymore, yet, across, along,
   everywhere, anywhere, myself, also, again, soon, already, almost.
4. **BROAD SOCIAL / POLITICAL / CULTURAL concepts** that can be explained in one simple
   sentence — KEEP (do NOT confuse with specific events). Examples:
   - leader ("a person who helps others decide") KEEP
   - vote ("when people choose by raising hands") KEEP
   - empire ("a big country that rules other lands") KEEP
   - revolution ("when many people want a big change") KEEP
   - officer, librarian, doctor, teacher KEEP (jobs)
   - others, panel, group, team KEEP (collective nouns)
   - pray, explain, unite, share, help KEEP (interpersonal actions)
5. **WORLD RELIGIONS / MAJOR CULTURES / HOLIDAYS that 5-year-olds encounter** — KEEP:
   christmas, easter, halloween, islam, buddhism, catholic, jewish, hindu, french,
   british, american, korean, chinese, indian, african — even though they sound like
   "specific" terms, 5-year-olds hear and use them. Drop only OBSCURE specific names
   (Wollstonecraft, Galilei, Tagore, Faraday).
6. **UNIVERSALLY FAMOUS NAMES** a child encounters via brand/character — KEEP:
   einstein (= "very smart person"), disney (= "cartoon company"), santa.
   Drop only obscure historical figures.
7. **EVERYDAY ABSTRACT NOUNS** that can be paraphrased — KEEP:
   stuff ("things"), habit ("something you do every day"), fee ("money you pay"),
   lab ("a science room"), hmm ("thinking sound"), social ("with friends"),
   max/min ("biggest/smallest"). DROP only TECHNICAL specialist terms with no plain
   equivalent (photosynthesis, mitochondria, myocardial).

# DROP criteria (apply ONLY after v2 KEEP rules above failed)
1. **OBSCURE proper nouns** — specific names a 5-year-old has never heard:
   Wollstonecraft, Tagore, Faraday, Galilei, Sigmund, Freud, Mesopotamia, Hippocrates,
   Robespierre. DROP. (But broad religion/culture KEEP per rule 5.)
2. **Pure technical/scientific specialist terms** with no 5-year-old paraphrase:
   photosynthesis, mitochondria, myocardial, infarction, periodic, logarithm,
   trigonometry, algebra, metabolism, photon, genetics, linguistics, macroeconomics.
3. **Adult / sensitive**: drug, sex, war, suicide, addiction, genocide.
4. **Pure tense/plural surface forms** that are just conjugations of a more common
   base form: made (=make), came (=come), gave (=give), sat (=sit), ate (=eat), felt
   (=feel), sang (=sing), began (=begin), knew (=know), met (=meet), became (=become).

# CATEGORY taxonomy (use only when keep=true; pick ONE best fit)
animal | plant | body | nature | weather | object | food | place | family | feeling
| action | property | clothing | tool | toy | sound | manner | quantity | time
| job | concept | culture | religion | name | other

# Output rules
- Output JSONL only. One JSON object per input lemma, in the SAME order as input.
- Each line: {"id": <int>, "lemma": "<original lemma>", "keep": <bool>,
  "category": "<one of taxonomy or null>", "reason": "<<=30 Korean chars>"}
- **`reason` MUST be written in Korean (한국어)**. Concise, <=30 characters.
- No prose before or after. No markdown fences.
